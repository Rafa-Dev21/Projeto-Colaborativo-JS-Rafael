# 🧩 Objetos e Propriedades no JavaScript

## 📖 Sobre o Tema
Os objetos são uma das estruturas fundamentais do JavaScript. Eles permitem armazenar e organizar dados de forma estruturada por meio de pares de chave e valor, facilitando o acesso, atualização e manipulação das informações dentro de um programa.

Cada propriedade de um objeto representa uma característica ou dado, e pode conter qualquer tipo de valor — texto, número, função ou até outros objetos.

## 🧠 O que foi estudado
Durante o desenvolvimento deste projeto, foram explorados os seguintes conceitos:

- Criação e acesso a propriedades.
- Atualização e remoção de propriedades.
- Métodos avançados:
  - `Object.keys()` — retorna as chaves do objeto.
  - `Object.values()` — retorna os valores.
  - `Object.entries()` — retorna pares [chave, valor].
- Casos de uso reais e aplicação prática.
